OrdinaryShade 0.1.0a5 provides the compiler features required by OrdinaryLight 0.4.0's shader migration.

- Typed compile-time variants, output parameters, runtime-array lengths, and 3D storage images.
- Additional math, packing, and Vulkan atomic intrinsics and image formats.
- Fixes for vector bitcasts, loop-local types, graphics resource access, and resource-free helpers.
- Explicit errors for unsupported WGSL operations.

Validation: 106 compiler tests passed; one optional test skipped. OrdinaryLight's complete shader inventory and representative Vulkan/WebGPU rendering checks passed with this compiler.

This is an alpha release. Install its wheel alongside the OrdinaryLight 0.4.0 wheel; the compiler is not yet published to PyPI by this workflow.
