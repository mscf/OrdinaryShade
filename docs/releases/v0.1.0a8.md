# OrdinaryShade 0.1.0a8

Add typed GPU primitives used by resident geometry and voxel-output pipelines.

- Fixed-size workgroup arrays through `osh.shared(osh.array(type, count))`, with GLSL and WGSL lowering. Applications provide initialization and barriers.
- Explicit `buffer_float32_atomic_add` capability and scalar storage-buffer `osh.atomic_add` support in GLSL. Reject missing capabilities, mismatched scalar types, non-buffer targets, and unsupported WGSL compilation.
- Ray-query triangle candidate confirmation through `query.confirm_intersection()`.

Floating-point atomic addition requires the corresponding Vulkan device features;
it does not enable shared-memory or image atomics. Sum rounding depends on GPU
execution order. This remains a pre-alpha compiler release.
